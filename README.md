

Data, code, and a reproducible manuscript for "*Cultural invariance in music-evoked emotions*" (Yurdum et al., 2026)

> [!IMPORTANT]  
> This repository requires git-lfs

To procedurally generate the manuscript and run analyses, first open the R project (`evoke-project.Rproj`) to set the working directory.  

The project uses `renv `to manage package versions. On first use, run:

`install.packages("renv")`
`renv::restore()`

The analyses have been successfully run under R 4.4.3 and R 4.5.1. Compatibility with R 4.6 or later has not been tested.

Directory structure:

* `/data` 
  * Contains lightly processed data and various metadata files for the songs included in the study, the NRC-VAD lexicon (Mohammad et al. 2025), and secondary data from Yurdum et al., (2023). 
  * The cleaned weather data are saved as `gsoy_compiled.csv.gz`. The original files are too large to host.
  * The lightly processed study data is saved as `tml_wwl_data.csv.gz`
* `/writing` 
  * The manuscript can be generated by running `manuscript.Rmd`. This file draws on results saved in `/results` and produces `manuscript.pdf`
  * The supplementary materials can be generated by running `supplementary.Rmd`. This file draws on results saved in `/results` and produces `supplmentary.pdf`
* `/analysis`
  * Analysis files are named in the order they should be run in if you want to recreate the paper from scratch. However, because the results of each script are saved in `/results` you should be able to run each script on its own without running into dependency issues.
* `/results`
  * Results of each analysis script are saved as RData files with their corresponding number (e.g., 03_imputation.R saves its results to 03_imputation_results.RData). 
  * The dataframes produced as a result of the imputation scripts are separately saved to the folder `./results/imputations`.
* `/evoke_player` contains the scripts and files necessary to run the paper's accompanying Shiny app. 
* `/viz` contains the procedurally generated and annotated figures used in the manuscript.
  * `annotated_figs.pptx`: Some figures were manually annotated for the paper in Powerpoint. The annotated figures are identical to the procedurally generated figures, except for significance stars and minor cosmetic edits.
